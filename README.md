# Proyecto: Calculadora de IMC en Python

## Descripción del programa
Este programa es una herramienta interactiva de consola desarrollada en Python que calcula el Índice de Masa Corporal (IMC) de un usuario. 
Captura información personal (nombre, edad, peso y estatura), procesa los datos aplicando validaciones para evitar errores por entradas incorrectas o campos vacíos, y finalmente devuelve un reporte formateado y estructurado con el resultado del IMC.
## Instrucciones de ejecución
Para ejecutar este programa necesitas tener Python instalado (o usar un entorno en línea como Replit o Google Colab).
1. Abre tu terminal o consola.
2. Navega hasta el directorio donde se encuentra el archivo.
3. Ejecuta el siguiente comando:
   `python calculadora_imc.py`
4. Sigue las instrucciones en pantalla e ingresa los datos solicitados.

Aprendí a manejar el control de versiones con Git (creando commits estructurados), a manipular cadenas de texto con f-strings y métodos como `.title()`, y a implementar validaciones con bloques `try-except` para hacer que el software sea resiliente ante errores humanos.
